# Їжачі баталії / Hedge Wars

The first game in Ігротека: a planned 2–4-player artillery game with destructible terrain, client rendering and a self-hosted authoritative server.

This directory owns the game. The Git repository and npm workspace root are one level above. Run commands from there; do not create a separate lockfile or Git repository here.

Current behavior: Ukrainian workshop page, interactive Phaser illustration and a validated network hello. No rooms, playable physics, weapons or terrain destruction yet.

Start with [handoff](docs/HANDOFF.md), [technical specification](docs/TECH_SPEC.md), [checklist](docs/CHECKLIST.md), [acceptance criteria](docs/ACCEPTANCE.md) and [agent instructions](AGENTS.md).
